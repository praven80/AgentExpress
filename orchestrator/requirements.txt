# --- An agentic framework used BY A SUB-AGENT, not by this framework -----------
# An agent under app/subagents/<id>/ may be authored with whatever framework you
# like. Strands is here because a shipped sample agent uses it (web_search); it
# reaches the model through ctx.llm via app/subagents/_shared/strands_bridge.py, so
# guardrails, cost telemetry, memory and truncation detection still apply. The
# orchestrator does not need it and the import is lazy — remove this line and the
# `think=` argument in web_search/agent.py and that agent falls back to a single
# plain ctx.llm call.
#
# BUDGET FOR ONE OF THESE BEFORE ADDING IT. There is ONE container image for every
# agent, so every agent pays for every framework in it whether it uses one or not.
# Measured on python3.13 site-packages:
#   requirements.txt as it stands   153 MB
#   + strands-agents                166 MB  (+13 MB)
# For comparison, CrewAI was measured at 804 MB (+651 MB — pyarrow, lancedb,
# onnxruntime, chromadb, kubernetes, grpc, numpy, openai, tokenizers) and caps the
# project at Python <3.14, which is why it is documented as a pattern rather than
# shipped. LangGraph costs nothing extra: it is already the outer orchestrator, and
# knowledge_research nests a graph of its own inside it.
strands-agents>=1.56.0,<2
